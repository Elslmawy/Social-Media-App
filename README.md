# Route Posts - Social Media Web Application

A lightweight, pixel-perfect clone of Route Posts built with React, Vite, and Tailwind CSS v4, connecting directly to the real Route Posts API.

## Features
- **Authentication**: Sign up with field validation (password rules, email check, matching passwords) and Sign In.
- **Feed**: 3-column responsive layout with Sidebar filters (Feed, My Posts, Community, Saved), Create Post with image preview and privacy selector, real-time post feed with pagination, and Suggested Friends with search and follow actions.
- **Post CRUD**: Create, edit, delete, like toggle, bookmark, and share with real-time feedback and modal confirmations.
- **Post Details**: Dedicated thread view with all comments, add comment with photo, and comment editing/deletion for owners.
- **Profile**: Gradient cover, overlapping profile card, followers/following/bookmarks stats, profile photo upload, and tabbed view of user posts and bookmarks.
- **Notifications**: Real-time notifications feed with unread filter, mark as read, and mark all as read.
- **Settings**: Change password with validation and automatic re-authentication.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.
